# 《我的》需求文档

> 关联文档：`00-产品总览与公共规则.md`

---

## 1. 模块目标

《我的》是用户的**账户中心 / 企业管理中心 / 资产管理中心**，承担以下职责：

1. **身份**：展示个人信息、当前企业、已开通服务概览。
2. **资产**：订单、发票、服务订阅、电子合同管理。
3. **企业**：企业切换、创建、加入、升级（采购企业 → 钢贸企业）、ERP 关联。
4. **协作**：员工与权限分配、智能机器人自动化流程。
5. **设置**：通知偏好、关于、退出账号、隐私协议等。

## 4. 模块 B · 已开通服务卡

### 4.1 顶部

- 左侧标题"已开通服务"
- 右侧标题"X 项"（已开通服务数量，含试用、即将到期，不含已到期）
- 右侧 CTA："去服务市场 >" → 跳转《我的服务》

### 4.2 列表项

| 字段 | 内容 |
| --- | --- |
| 服务图标 + 简称 | 如「库」「收」「录」 |
| 服务全名 | AI 库存 / AI 出纳 / AI 录入 |
| 状态徽标 | 已开通 / 试用中 / 即将到期 |
| 到期时间 | "续费至 2026-12-31" / "试用至 2026-05-05" |
| 操作 | "进入" 蓝色按钮 |

### 4.3 交互

| 行为 | 处理 |
| --- | --- |
| 点击"进入" | 校验登录、企业、服务订阅、个人权限；通过则进入对应子系统首页；无权限提示 `管理员及超管默认拥有权限，其他成员暂未授权，请联系企业管理员开通该服务/权限` |
| 点击列表项空白处 | 同"进入" |
| 滑动卡片 | 不分页；最多 5 条 + "查看更多 >"，跳转《我的服务》 |
| 右上"去服务市场 >" | 跳转《我的服务》 |
| 试用中 | 在卡片底部展示"还剩 X 天，去续费 >" |

### 4.4 数量校准

`X` 与首页"已开通服务 X / 6"中的 X 一致；后端同源接口。

## 5. 模块 C · 我的订单

### 5.1 入口

列表行：`我的订单` + 右侧文案 `3 笔订单 >`（数字为待支付/进行中订单数）

### 5.2 权限规则

| 角色 | 显示范围 |
| --- | --- |
| 超管 / 管理员 | 公司全部订单 |
| 普通员工 | 仅显示自己创建的订单 |

### 5.3 页面


| 操作 | 行为 |
| --- | --- |
| 点击 | 跳转订单详情：商品/规格/金额/支付方式/电子发票/电子合同 |

| 已支付 | "查看发票 / 申请退款（试用期内）" |
| 退款中 | 展示退款进度 |

### 5.4 接口

| --- | --- |

## 6. 模块 C · 发票管理

### 6.1 入口

列表行：`发票管理` + 右侧 `1 可开票 >`（金额为可开发票总数）。

### 6.2 权限规则

| 角色 | 范围 |
| --- | --- |
| 超管 / 管理员 | 公司全部发票（已开 + 未开） |
| 普通员工 | 仅自己的订单发票 |

### 6.3 页面结构

```
Tab：可开票 │ 开票记录 │ 抬头管理
```

**开票记录**：已开发票列表，含状态（开票中/已开/已作废）、操作（重发邮件/作废/下载）。

**抬头管理**：

| 字段 | 说明 |
| --- | --- |
| 抬头类型 | 企业 / 个人 |
| 抬头名称 | 必填 |
| 税号 | 企业必填 |
| 注册地址 | 选填 |
| 电话 | 选填 |
| 开户行 | 选填 |
| 开户账号 | 选填 |
| 收票邮箱 | 必填 |
| 默认 | 单选 |

### 6.4 接口

| 接口 | 用途 |
| --- | --- |
| `GET /invoices?status=` | 列表 |
| `POST /invoices` | 申请开票 |

## 7. 模块 C · 员工与权限

### 7.1 入口

列表行：`员工与权限` + 右侧 `已关联 ERP >`（或 `未关联`）

### 7.2 权限规则

仅"超管 / 管理员"可见可改。其他角色：

- 列表项右侧显示锁图标 + "管理员可见"。
- 点击提示：`管理员及超管默认拥有权限，其他成员暂未授权，请联系企业管理员开通`。

### 7.3 页面结构

```
顶部 Tab：成员 │ 角色 │ ERP 关联
```

**成员 Tab**：

| 列 | 内容 |
| --- | --- |
| 头像 + 姓名 | 微信昵称或 ERP 实名 |
| 角色 | 超管 / 管理员 / 普通员工 / 自定义角色 |
| 权限范围 | 显示可用服务列表（前 3 个 + "+N"） |
| 状态 | 在职 / 离职 |
| 操作 | 编辑权限 / 移除成员 / 转让超管 |

**角色 Tab**（按角色批量授权）：

| 列 | 内容 |
| --- | --- |
| 角色名 | 系统角色不可删；自定义角色可增删改 |
| 已绑定成员数 | n 人 |
| 权限范围 | 哪些服务的哪些操作 |

**ERP 关联 Tab**：

- 关联状态：已关联（显示 ERP ID）/ 未关联
- 操作："关联 ERP / 解除关联"
- 关联后：可同步 ERP 员工花名册、组织架构、单据；解除后保留本地数据，但停止同步。

### 7.4 授权方式

按思维导图说明，支持两种粒度：

1. **按角色设置**：设置角色权限，成员绑定角色继承；适合人多企业。
2. **按人员设置**：对单个成员开放/收回某个服务及功能模块；适合定制化场景。

### 7.5 接口

| 接口 | 用途 |
| --- | --- |
| `GET /members` / `POST /members/invite` | 成员管理 |
| `GET /roles` / `POST /roles` | 角色管理 |
| `POST /members/{id}/permissions` | 按人设权限 |
| `POST /erp/bind` / `POST /erp/unbind` | ERP 关联 |

## 8. 模块 C · 企业切换

### 8.1 入口

列表行：`企业切换` + 右侧显示当前企业名（如"上海钢贸"）

### 8.2 数据展示规则

> 思维导图明确：仅支持显示**钢贸企业**以及**钢贸关联绑定的独家企业**。

页面分两部分：

**当前企业卡**

| 字段 | 说明 |
| --- | --- |
| 企业名 + "当前"红色徽标 | |
| 标签 | 企业简称、ERP 关联状态 |
| 企业全称 | |
| 税号 | |
| 法定代表人 | |
| 注册地址 | |
| 成立日期 | |
| 营业执照号 | |
| ERP ID | 仅已关联展示 |

**其它已加入企业**（可滑动列表）

每张卡片：

| 字段 | 说明 |
| --- | --- |
| 企业名 + 标签 | "钢贸智贸""新建已同步"等 |
| 同上字段集合 | |
| 底部操作 | 「切换至此」蓝色主按钮 + 「移出列表」红色边框 |

### 8.3 加入新企业

底部固定两个高亮入口：

1. **上传营业执照添加** → 调用 OCR 识别 → 自动匹配 ERP → 创建企业（提交后等待审核或直接创建）。
2. **输入名称关联现有企业** → 关键词搜索 → 显示候选企业 → 选定后申请加入（需对方管理员审批）。

### 8.4 创建 / 加入 / 升级流程

| 流程 | 入口 | 步骤 |
| --- | --- | --- |
| 创建企业 | 上传营业执照 | OCR → 校验工商数据 → 选择企业类型（钢贸/采购）→ 完善 ERP → 创建成功 |
| 加入企业 | 输入名称 | 搜索 → 申请 → 对方超管审批 → 加入 |
| 升级（采购→钢贸） | 当前企业为采购时，企业卡顶部显示"升级为钢贸企业"按钮 | 上传补充资质 → 平台审核 → 通过后角色变更 |

### 8.5 切换企业行为

| 步骤 | 行为 |
| --- | --- |
| 1 | 点击「切换至此」 |
| 2 | 弹窗确认：`确定切换至 XX 企业？切换后将以该企业身份使用所有服务。` |
| 3 | 切换成功 → 全局上下文更新（首页、服务、消息、我的全部刷新） |
| 4 | Toast：`已切换至 XX` |

### 8.6 移出列表

- 仅退出该企业的成员身份，不删除企业本身。
- 当前企业不可移出，需先切换到其他企业。
- 二次确认弹窗：`移出后将无法使用该企业的所有服务，是否继续？`

## 9. 模块 C · 智能机器人

### 9.1 入口

列表行：`智能机器人` + 右侧角标【重磅推出】 / 【已开通】 / 【未开通】

### 9.2 业务说明

允许用户**设定一段流程**，由小助理自动化执行操作。例如：

- 当 AI 出纳识别到一笔回款 → 自动匹配应收单 → 自动通知业务确认 → 自动归档；
- 当 AI 库存检测到某品类库龄 > 45 天 → 自动通知业务 + 在企业群发提醒 + 创建营销任务。

### 9.3 页面结构

```
顶部：我的机器人（已创建流程） / 模板市场（运营推荐）
```

| 字段 | 说明 |
| --- | --- |
| 名称 | 用户自定义 |
| 触发器 | 来自某服务的事件（如「库龄>45 天」「银行流水入账」）|
| 动作链 | 一个或多个动作，顺序执行（条件分支、延时、人工确认节点） |
| 状态 | 启用 / 停用 / 草稿 |
| 最近执行 | 时间 + 成功率 |
| 操作 | 编辑 / 启停 / 复制 / 删除 / 查看运行记录 |

### 9.4 权限

仅"超管/管理员"或拥有"自动化流程"权限的成员可创建/启停；普通成员只读可见自己被涉及的流程。

### 9.5 重磅推出阶段

- 列表项右侧角标 `【重磅推出】`；
- 点击进入预约页：介绍 + "预约通知 / 申请内测"按钮；
- 提交后写入预约表，正式开放后通过订阅消息通知。

## 12. 全局规则

| 项 | 规则 |
| --- | --- |
| 权限校验 | 所有"管理员可见"项按总览 3.3 提示文案 |
| 多企业切换 | 切换后全局上下文广播；所有 Tab 数据刷新 |
| 企业类型限制 | 当前企业为采购企业：服务相关入口仍可访问，但触发购买/试用时引导升级 |
| 风险提示 | 所有"敏感操作"（移出企业、退出账号、转让超管、解除 ERP）需二次确认 |
| 文案合规 | 涉及金额、电话、邮箱、税号等字段一律用对应格式 |

## 14. 异常与边界

| 场景 | 处理 |
| --- | --- |
| 未登录 | 仅展示登录引导 + 静态信息（如版本号、协议、关于） |
| 未加入企业 | 隐藏"我的订单 / 发票 / 员工与权限 / 服务卡片"，引导关联企业 |
| 当前企业被超管移除 | 弹窗提示并自动回到企业切换页 |
| 当前企业被解散 | 提示 + 强制切换至其他企业；若无其他企业，回到"未关联企业"状态 |
| 网络异常 | 用户卡保留缓存，列表项右侧文案显示"--"占位，点击仍可刷新 |
