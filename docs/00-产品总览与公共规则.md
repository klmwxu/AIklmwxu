## 3. 用户角色与权限模型

### 3.1 平台账户层级

| 层级 | 说明 |
| --- | --- |
| 个人微信账号 | 通过微信授权登录，唯一身份标识 |
| 企业（租户） | 一个微信账号可加入 / 创建多个企业，但同一时间只激活一个"当前企业" |
| 服务订阅 | 以"企业"为单位订阅 AI 服务，订阅有效期内可分配给企业员工 |

### 3.2 企业内角色

| 角色 | 权限 | 备注 |
| --- | --- | --- |
| 超级管理员（超管） | 企业内最高权限；可管理订阅、订单、发票、成员、角色、权限、所有服务 | 默认为企业创建人；可转让 |
| 管理员 | 与超管权限基本一致，但不能解散企业、不能转让超管 | 由超管设置 |
| 普通员工 | 仅可使用被授权的服务与功能 | 由超管/管理员分配权限 |
| 访客 | 未登录或未加入任何企业 | 仅可浏览商城、试用部分 AI |

### 3.3 权限校验通用规则

- 所有受权限保护的入口点击后，先检查"是否登录 → 是否已加入企业 → 是否拥有当前服务/功能权限"。
- 任一校验不通过时，使用以下统一提示文案：
  - 未登录：`请先登录后使用该功能`，跳转至授权登录。
  - 未加入企业：`请先创建或加入企业后使用该功能`，跳转至《我的 → 企业切换》。
  - 已加入但服务未开通：`该服务尚未开通，是否立即前往开通？`
  - 服务已开通但无个人权限：`管理员及超管默认拥有权限，其他成员暂未授权，请联系企业管理员开通该服务/权限`。

## 4. 核心服务（AI 服务矩阵）

> 商城与各模块统一引用本表。所有服务支持：①免费试用；②单买；③套餐打包购买。

| 编号 | 服务名 | 一句话能力 | 面向角色 | 单买参考价 | 关键能力 |
| --- | --- | --- | --- | --- | --- |
| S01 | AI 库存 | 入库 / 出库 / 盘点 / 库龄预警 | 仓管、业务 | 起售价 ¥99/月 | 库存看板、库龄预警、出入库单据自动生成、ERP 同步 |
| S02 | AI 出纳 | 收付款 / 银行流水自动对账 | 财务、老板 | 起售价 ¥99/月 | 银行流水拉取、自动匹配、异常告警、资金日报 |
| S03 | AI 录入 | 过磅单 / 合同 / 票据 OCR | 业务、单证 | 起售价 ¥99/次 | 多票据 OCR、结构化字段抽取、推送各业务系统 |
| S04 | 提货宝 | 提货码 / 司机核验 / 道闸联动 | 司机、仓库、客户 | 起售价 ¥198/月 | 一码提货、司机身份核验、道闸/磅秤联动、电子签收、车牌/人脸识别 |
| S05 | 对账宝 | 上下游月结 / 差异挂账 | 财务、业务 | 商城详情页显示 | 多维对账、差异挂账、协同确认 |
| S06 | 钢贸征信 | 客户征信 / 授信预警 | 老板、业务、风控 | 商城详情页显示 | 工商穿透、司法风险、舆情、授信额度建议 |

> 套餐示例：
> - 套餐 A（业务起步包）：AI 库存 + AI 录入
> - 套餐 B（财务管家包）：AI 出纳 + 对账宝
> - 套餐 C（钢贸全家桶）：S01～S06 全量
>
> 注：在《我的服务》与《我的》模块若出现"购买"动作，需说明"套餐 X 中已包含 AI 库存 + AI 出纳 + AI 录入"等组合关系，避免重复购买；已开通的子项在套餐购买页须自动置灰并提示"已开通将顺延有效期"。

## 5. 服务订阅状态

| 状态 | 含义 | UI 标签颜色 | 操作按钮 |
| --- | --- | --- | --- |
| 未开通 | 企业从未购买/试用 | 灰 | "立即开通" / "免费试用" |
| 试用中 | 处于免费试用期 | 黄 | "进入"、"立即开通" |
| 已开通 | 在订阅有效期内 | 绿 | "进入" |
| 即将到期 | 距到期 ≤ 30 天 | 橙 | "进入"、"续费" |
| 已到期 | 订阅过期未续费 | 红 | "续费" / "重新购买" |
| 重磅推出 | 平台新上线尚未发布定价 | 蓝 | "敬请期待" / "预约" |

> 各服务卡片右上角统一展示订阅状态徽标；首页"已开通服务"区域内仅显示绿/黄/橙状态。

## 6. 通用消息与待办字段

> 用于《首页》《消息》两个模块。所有"消息 / 待办 / 风险预警 / 审批"统一字段集合：

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 唯一 | 平台统一生成 |
| `type` | enum | 系统 / 待办 / 待审批 / 风险预警 | 一级分类 |
| `subType` | enum | 高风险 / 中风险 / 低风险 / 提醒 等 | 用于风险预警 |
| `source` | enum | S01～S06 + `platform` | 来源服务 |
| `title` | string | 最长 20 字符，超出"…" | 列表展示 |
| `summary` | string | 单行展示，超出"…" | 详情摘要 |
| `time` | datetime | ISO 8601 | 列表显示"今天 HH:mm / 昨天 / MM-DD" |
| `readStatus` | enum | 未读 / 已读 | 红点 |
| `handleStatus` | enum | 未处理 / 已处理 | 文字标签 |
| `deepLink` | string | scheme | 点击跳转的子系统页面 |

> 列表项排序规则：①未处理 > 已处理；②未读 > 已读；③时间倒序。

### 6.1 子系统跳转规则

- 列表项点击 → 进入对应子系统详情页。
- 子系统详情页左上角统一显示返回按钮：`< 返回 工作台`，点击回到平台 Tab 而非子系统上一级。
- 子系统首页（非详情）则显示 `< 上一页 / 主页`，主页 = 子系统首页。

### 6.2 已 / 未读 与处理状态显示矩阵

| 未读 | 处理 | 列表展示 |
| --- | --- | --- |
| 未读 | 未处理 | 红点 + "未处理" 标签 |
| 已读 | 未处理 | 无红点 + "未处理" 标签 |
| 已读 | 已处理 | 无红点 + "已读" 标签 |

## 8. 通用交互与异常

| 场景 | 处理 |
| --- | --- |
| 网络异常 | 显示空态 + "刷新重试" |
| 接口 401 | 静默重新拉取 token；二次失败回登录 |
| 接口 403 | 弹出权限不足提示（见 3.3） |
| 接口 5xx | Toast "系统繁忙，请稍后重试" |
| 下拉刷新 | 所有 Tab 主页支持 |
| 上拉加载 | 所有列表页支持，分页 20/页 |
| 骨架屏 | 首屏加载使用 |
| 文案合规 | 涉及金额一律带 ¥ 与千分位 |
