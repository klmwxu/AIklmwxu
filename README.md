# AI 钢贸小助理 · 产品需求文档（PRD）

本仓库为钢贸行业一站式 AI 聚合平台「AI 钢贸小助理」微信小程序的产品需求文档集合。所有文档位于 [`docs/`](./docs) 目录。

## 文档结构

| 序号 | 文档 | 说明 |
| --- | --- | --- |
| 00 | [产品总览与公共规则](./docs/00-产品总览与公共规则.md) | 信息架构、用户角色、权限模型、服务矩阵、状态规则、通用字段、术语表 |
| 01 | [首页（工作台）需求文档](./docs/01-首页（工作台）需求文档.md) | 经营驾驶舱：身份卡、核心服务、风险预警、今日待办 |
| 02 | [我的服务需求文档](./docs/02-我的服务需求文档.md) | 服务列表、商城、详情/套餐、下单/支付、试用/续费 |
| 03 | [消息需求文档](./docs/03-消息需求文档.md) | 待办 / 审批 / 系统 / 风险 四分类，跨子系统聚合与协作 |
| 04 | [我的需求文档](./docs/04-我的需求文档.md) | 账户、已开通服务、订单、发票、员工与权限、企业切换、智能机器人、设置 |

## 阅读建议

1. 先读 **00 总览**，理解角色、订阅、状态、消息字段等公共概念；
2. 再按 Tab 顺序阅读 01～04 模块文档，每篇均独立可实施；
3. 模块文档中遇到通用规则会标注"见总览第 N 节"，避免重复定义。
