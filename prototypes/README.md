# 货袋子 · 积分体系产品原型

> 基于 `PM-SKILL-01` 原型 UI 生成器技能产出
> 技术栈：Tailwind CSS v3 (CDN) + ECharts 5 (CDN) + 原生 HTML/JS
> 单文件可运行，浏览器直接打开即可预览

---

## 1. 文件说明

| 文件 | 角色 | 主要内容 |
|---|---|---|
| `index.html` | 入口导航 | 3 张大卡，跳转到下述三个原型 |
| `admin.html` | **后端运营后台**（管理员视角） | 数据看板 / 积分规则 / 积分流水 / 风控异常 / 商城管理 / 等级体系 |
| `user.html`  | **前端个人积分中心**（C 端用户） | Hero · 签到 · 今日任务 · 任务中心 · 30 天趋势 · 商城精选 · 积分明细 |
| `enterprise.html` | **前端企业积分中心**（企业管理员） | 企业 Hero · 4 KPI · 月度趋势 · 来源占比 · 员工 Top10 · 兑换权益 · 待审批 · 兑换记录 |

> **设计原则**：单 HTML 文件包含全部 CSS/JS/Mock 数据，无构建步骤、无外部静态资源，浏览器直接双击 `index.html` 即可预览。

## 2. 预览方式

### 方式 A：直接双击
- 任意浏览器（Chrome / Edge / Safari）打开 `index.html` 即可。
- 首次加载需要联网，CDN 加载 Tailwind 与 ECharts（约 200KB）。

### 方式 B：本地 Web 服务（推荐评审/演示）
```bash
cd prototypes
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

### 方式 C：在 IDE 中右键 "Open with Live Server"

## 3. 关键交互说明（≤ 10 条）

### 后端运营后台 `admin.html`
1. **左侧 sidebar 6 个 Tab** 互斥切换，URL 不变；面包屑随之更新；切换时 ECharts 实例自动 `resize`。
2. **积分规则**筛选区支持 类目 / 归属 / 目标 / 状态 / 关键字 5 维过滤；"查询"实时刷新；"重置"清空全部条件。
3. **新建/编辑规则**弹窗：表单含 编码 / 名称 / 类目 / 触发端 / PP / EP / 归属策略 / 上限 / 触发条件 / 启停；保存后 Toast 提示。
4. **流水详情**抽屉：行末"详情"按钮从右侧滑入；支持"查看用户"和"回收积分"操作。
5. **风控异常 KPI 卡** 左侧色条区分高/中/低风险；表格"冻结/回收"按钮直接触发。
6. **商城管理**卡片网格响应式：移动端 2 列、平板 3 列、PC 4 列。

### 前端个人积分中心 `user.html`
7. **快捷入口** 4 个 icon 平滑滚动到对应锚点（签到 / 任务 / 商城 / 明细）。
8. **明细 Tab**（全部 / 收入 / 支出）按钮高亮切换，列表实时过滤；空数据展示卡通空状态。
9. **底部固定 Tabbar** 模拟小程序原生 Tabbar，PC 端居中宽度 ≤ 640px。

### 前端企业积分中心 `enterprise.html`
10. **兑换权益**点击"立即兑换"打开统一弹窗，含余额校验 → 大额（≥ 50,000 EP）自动进入企业法人审批流程；"待我审批"模块批准/驳回单笔申请。

## 4. 视觉规范

| 角色 | 颜色 | HEX |
|---|---|---|
| 主色 · 钢铁蓝 | `steel` | `#1E40AF` |
| 强调色 · 钢深蓝 | `steelDark` | `#1E3A8A` |
| 警示 · 预警橙 | `warn` | `#F59E0B` |
| 成功 · 成长绿 | `ok` | `#10B981` |
| 危险 · 错误红 | `danger` | `#EF4444` |
| 背景 · 雪白灰 | `bg` | `#F8FAFC` |

- 字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei"`
- 圆角：卡片 12~16px、按钮 8~9999px、Hero 24px
- 阴影：浅默认；hover 时 +20px 大模糊。

---

## 5. 响应式断点

| 断点 | 阈值 | 主要适配 |
|---|---|---|
| 移动 | < 768px | 单列、Tabbar 固定底部、Sidebar 折叠 |
| 平板 | 768~1023px | 2~3 列布局 |
| PC | ≥ 1024px | 全功能视图，sidebar 永远展开 |

`admin.html` 在 < 768px 时左上角出现汉堡按钮，点击展开 sidebar。

## 6. 数据与字段约定（mock）

> 所有 mock 数据集中在每个 HTML 末尾 `<script>` 块顶部的常量，方便后续替换为真实接口返回。

- `RULES`：积分动作清单（编码 / 名称 / 触发端 / PP / EP / 上限 / 归属 / 目标）
- `RECORDS`：积分流水（流水号 / 账户 / 动作 / 方向 / 数值 / 业务号 / 状态 / 时间）
- `RISKS`：风控异常（账号 / 触发规则 / 风险等级 / 累计可疑积分 / 处理状态 / 最后触发）
- `MALL_ITEMS` / `REDEEMS`：商品/权益（名称 / 价格 EP / 类型 / 库存 / 标签）
- `STAFFS`：员工贡献 Top10（姓名 / 岗位 / 拉新数 / 发布数 / 询报价 / 订单贡献 / EP）
- `DETAILS`：个人积分明细（方向 / 标题 / 描述 / 数值 / 时间）
