# 《我的服务》需求文档

> 关联文档：`00-产品总览与公共规则.md`

---

## 1. 模块目标

《我的服务》Tab 是用户**浏览、试用、购买与续费** AI 服务的总入口，承担三类核心职责：

1. **服务总览**：一站式展示平台全量服务（不论是否开通）。
2. **商城入口**：所有 AI 服务/套餐/增值包售卖、结算、支付的统一收口。
3. **续费 & 升级管理**：到期提醒、续费、升级套餐操作。

---

## 4. 模块 ② · 服务列表

### 4.1 排序规则（自上而下）

| 优先级 | 分组 | 说明 |
| --- | --- | --- |
| P0 | **热门** | 平台运营后台手动配置（最多 3 个），右上角徽标"热门" |
| P1 | **已开通** | 已订阅且未到期；可在右上角看到"已开通"绿色徽标 |
| P2 | **试用中** | 处于试用期，"试用中"黄色徽标，并展示剩余天数 |
| P3 | **即将到期** | 距到期 ≤ 30 天，橙色徽标 |
| P4 | **未开通** | 未购买/已到期 |

> 同一服务可能同时归属"热门"和"已开通"，按 P0 显示在顶部"热门"分组中。同一服务在分组之间只显示一次（去重）。

### 4.2 服务卡片字段

| 字段 | 数据来源 | 说明 |
| --- | --- | --- |
| 服务图标 | 商品中心 | 80×80，圆角 16 |
| 服务名 | 商品中心 | 主标题，加粗 |
| 子标题 | 商品中心 | 三段式描述：能力 · 能力 · 能力（如"入出库 / 盘点 / 库龄预警"） |
| 面向角色 | 商品中心 | "面向：仓管 / 业务" |
| **参考价**（关键规则） | 见 4.3 | "起售价 ¥99/月" 或 实际单品价 |
| 状态徽标 | 见总览第 5 节 | 已开通 / 试用中 / 即将到期 / 未开通 / 已到期 |
| 操作按钮 | 见 4.4 | "进入" / "立即开通" / "购买" / "续费" / "免费试用" |

### 4.3 参考价显示规则

> 这是一条非常重要的业务规则，避免商品中心与套餐绑定混乱。

| 商品中心是否存在独立 SKU | 显示价格 | 点击"购买"动作 |
| --- | --- | --- |
| **存在** | 直接显示该 SKU 实际价（如 `¥198/月`） | 进入该 SKU 详情页 → 加入购物车 / 立即购买 → 结算 → 支付 |
| **不存在**（该服务只在套餐里提供） | 显示"起售价 ¥99/月"等参考价 | 进入"包含该服务的套餐列表" → 选择具体套餐 → 进入套餐详情 → 结算 |

> 即：**有单买就单买，没有单买就引导买套餐**。所有购买入口都必须落到《商城详情页》。

### 4.4 状态-操作矩阵

| 状态 | 主操作按钮 | 次操作按钮 | 备注 |
| --- | --- | --- | --- |
| 已开通 | "进入" | / | 进入子系统首页前先校验个人权限 |
| 试用中 | "进入" | "立即开通" | 子系统顶部条提示"试用还剩 X 天" |
| 即将到期 | "进入" | "续费" | 进入续费选择套餐/时长 |
| 已到期 | "续费" | / | 进入续费 SKU |
| 未开通 | "立即开通" / "购买" | "免费试用"（若该服务支持试用） | 文案根据是否有独立 SKU 自动切换 |
| 重磅推出 | "敬请期待" | "预约通知" | 不可购买 |

### 4.5 点击行为详细说明

| 区域 | 行为 |
| --- | --- |
| **整卡点击** | 等同于点击主操作按钮（已开通则进入，未开通则进入详情/购买） |
| 状态徽标点击 | 弹气泡说明该状态含义（如"试用中：体验期 30 天，到期需购买或停用"） |
| 操作按钮"进入" | 进入子系统；无权限提示按总览 3.3 |
| 操作按钮"购买/续费" | 按 4.3 规则进入详情或套餐列表 |
| 操作按钮"免费试用" | 调试用接口：创建一条 30 天试用订阅，刷新本页 |

### 4.6 空状态

- 商城无任何服务（极端运营状态）：插画 + "服务暂未上架，敬请期待"
- 接口异常：插画 + "服务列表加载失败，点击重试"

## 5. 子页面 · 服务/套餐详情页

> 路径：`pages/services/detail?spuId=xxx`

### 5.1 页面结构

```
┌────────────────────────────────────────────┐
│ ← 返回                                     │
├────────────────────────────────────────────┤
│ 顶部 Hero：彩色背景 + 服务图标 + 服务名     │
│ 副标题：能力1 / 能力2 / 能力3              │
├────────────────────────────────────────────┤
│ 概述文字：1～2 行简介                       │
├────────────────────────────────────────────┤
│ 核心能力（icon + 标题列表，5～8 条）         │
├────────────────────────────────────────────┤
│ 选择套餐（SKU 卡，可水平滑动）              │
│   - 标准版 ¥198/月                         │
│   - 专业版 ¥598/月                         │
│   - 旗舰版 ¥1,288/月（可选）               │
├────────────────────────────────────────────┤
│ 套餐包含明细                               │
│ ┌── 选中"标准版"时展示其能力点 ─────┐      │
│ │ 1000 次提货码 / 月                  │      │
│ │ 5 用户                              │      │
│ │ 基础核验                            │      │
│ └────────────────────────────────────┘      │
├────────────────────────────────────────────┤
│ 底部固定栏：                                │
│ 已选：标准版  ¥198/月  [免费试用][立即开通]  │
└────────────────────────────────────────────┘
```

### 5.2 套餐与子服务关系展示规则

- 若 SPU 是**单服务**：直接显示该服务能力。
- 若 SPU 是**套餐**：列表显式列出"本套餐包含：AI 库存 + AI 出纳 + AI 录入"。
- 若用户已开通其中部分子服务：在子服务名右侧显示"已开通"灰色徽标，并在底部栏增加文案：`您已开通部分子服务，购买套餐将自动延长这些子服务的到期时间`。
- 若用户已开通**全部子服务**：底部"立即开通"改为"续费整套"，文案改为"该套餐内服务您已全部开通，购买将顺延所有有效期"。

### 5.3 操作按钮

| 按钮 | 条件 | 行为 |
| --- | --- | --- |
| 免费试用 | 当前 SPU 支持试用 & 当前企业未试用过 | 创建试用订阅 → 跳转子系统首页 |
| 立即开通 | 默认 | 进入下单页 §7 |
| 续费 | 当前 SPU 已开通 | 进入续费页（默认续 12 个月） |

### 5.4 校验顺序

进入"立即开通 / 续费"前依次校验：

1. 已登录；
2. 已加入企业且当前企业为钢贸企业（采购企业则提示升级）；
3. 用户为超管/管理员，或拥有"采购管理"角色权限；普通员工 → 提示`请联系企业管理员/超管完成开通`。

## 7. 子页面 · 下单（购物车/立即购买/结算/支付）

### 7.1 下单流程

```
SPU 详情 → 选规格 → 立即购买/加入购物车
        ↘ 购物车
                ↓
            结算页（确认企业 / 数量 / 时长 / 优惠券 / 发票 / 协议）
                ↓
            微信支付（小程序原生）
                ↓
            支付结果页（成功 / 失败 / 处理中）
                ↓
            可"进入服务" / "查看订单" / "返回我的服务"
```

### 7.2 结算页字段

| 字段 | 说明 |
| --- | --- |
| 购买企业 | 默认为当前企业，可切换（仅限当前用户为超管/管理员的钢贸企业） |
| 商品清单 | 包含 SPU、规格、数量、单价、小计 |
| 购买时长 | 月/季/年（年付通常打 8 折，由运营配置） |
| 优惠券 | 选择可用券；显示折扣 |
| 发票信息 | 默认走当前企业发票抬头；可现场修改 |
| 用户协议 | 勾选《钢贸小助理服务协议》 + 《增值服务付费协议》 |
| 总价 | ¥X,XXX.XX |

### 7.3 支付规则

- 仅支持微信支付（小程序）。
- 支付成功后：① 写入订单；② 立即同步开通服务；③ 推送平台站内信通知。
- 支付失败：保留订单为"待支付"，30 分钟内可继续支付，超时自动关闭。

### 7.4 试用规则

| 规则 | 说明 |
| --- | --- |
| 试用期 | 默认 30 天（按服务可配置） |
| 试用次数 | 同一企业 + 同一服务，仅可试用 1 次 |
| 试用提示 | 试用到期前 7 天，每天在首页与本页顶部出现"即将到期"横条 |
| 试用结束 | 自动转入"已到期"状态；功能锁定，数据保留 90 天 |

## 9. 数据接口约定（草案）

| 接口 | 用途 |
| --- | --- |
| `GET /services/list` | 服务列表（携带订阅状态、排序分组） |
| `GET /spu/detail?spuId=` | 服务/套餐详情 |
| `GET /spu/{id}/skus` | SPU 下所有 SKU |
| `POST /trial/apply` | 申请试用 |
| `POST /cart/add` | 加入购物车 |
| `POST /order/create` | 创建订单 |
| `POST /pay/wechat` | 调起微信支付 |
| `GET /order/{id}` | 订单详情 |
| `POST /service/{id}/renew` | 续费 |

## 10. 异常与边界

| 场景 | 处理 |
| --- | --- |
| 当前企业为采购企业，点击购买 | 弹窗 `当前为采购企业，需升级为钢贸企业，是否立即升级？` |
| 普通员工点击购买 | 弹窗 `仅超管/管理员可购买服务，请联系企业管理员` |
| 已开通服务再次点击"购买" | 引导至续费/升级页，而非重新下单 |
| 试用已使用过 | "免费试用"按钮置灰，气泡 `本企业已使用过试用` |
| 支付中断 | 保留订单 30 分钟，订单页底部"继续支付" |
| 商品已下架 | 详情页弹窗 `该商品已下架，去看看其他套餐 >` |
